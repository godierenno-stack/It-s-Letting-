# CheboreJr - Company Website

A modern, responsive company website for **CheboreJr**, built with HTML, CSS, and JavaScript.

## Features

- **Responsive Design** - Mobile-first approach that works seamlessly on all devices
- **Modern UI** - Clean typography, smooth animations, and professional color scheme
- **Interactive Elements** - Mobile navigation toggle, smooth scrolling, animated counters, and card tilt effects
- **Contact Form** - Client-side form validation with real-time feedback
- **Accessible** - Semantic HTML with ARIA labels and keyboard-friendly navigation

## Project Structure

```
├── index.html          # Main landing page
├── css/

├── js/
│   └── main.js         # Interactive functionality
├── assets/             # Images, logos, and other media
```

## Sections

- **Header** - Fixed navigation with CheboreJr branding
- **Hero** - Company tagline with animated statistics
- **About Us** - Company story and core values
- **Services** - Web Development, Mobile Apps, Cloud Solutions, UI/UX Design, Cybersecurity, Data Analytics
- **Portfolio** - Showcase of recent projects
- **Testimonials** - Client reviews and feedback
- **Contact** - Contact form with validation and company contact info
- **Footer** - Company info, quick links, and social media links

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/godierenno-stack/It-s-Letting-.git
   ```

2. Open `index.html` in your browser, or serve with any static file server:
   ```bash
   # Using Python
   python3 -m http.server 8000

   # Using Node.js
   npx serve .
   ```

3. Visit `http://localhost:8000` in your browser.
